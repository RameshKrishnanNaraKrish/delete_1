    Fix trailing comma and add IPv4 LHOST validation specs
    
    - Remove stray trailing comma after the 'Payload' hash key that was
      left behind when the 'Notes' block was removed via GitHub's Apply
      Suggestion flow. This was tripping rubocop's
      Style/TrailingCommaInArguments cop and causing the Lint/msftidy CI
      check to fail. Caught by @bwatters-r7.
    
    - Add three specs exercising the IPv4-only LHOST validation:
      * IPv6 address ('2001:db8::1')
      * IPv6 loopback ('::1')
      * Hostname ('www.example.com')
      Each verifies that #generate raises ArgumentError with the
      'LHOST must be in IPv4 format' message. Requested by @bwatters-r7
      to explicitly cover the failure conditions of the IPv4 check
      added in an earlier commit.
